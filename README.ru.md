# Inverter Dashboard Go

[English](README.md) · [Русский](README.ru.md) · [Українська](README.uk.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Nederlands](README.nl.md)

Веб-панель для установки Victron: сервер на Go со встроенным интерфейсом Vue. Данные поступают напрямую от Cerbo по MQTT или через HTTPS inverter-gateway (IGW). Home Assistant можно подключить отдельно для домашних устройств и датчиков. Для запуска готового бинарного файла Node.js и npm не нужны.

![Архитектура: MQTT или HTTPS-шлюз передают данные серверу Go; Home Assistant, браузер и приватное хранилище подключаются отдельно.](docs/assets/architecture.svg)

В [иллюстрированном руководстве по процессу и результатам](docs/process-and-results.md) описаны этапы обновления, исправление проверки интервала опроса HA и правила словаря Home со стабильными ключами. Результаты тестов исходного кода отделены от подтверждения релиза, развёртывания и проверки в браузере.

## Возможности

- Сеть, аккумуляторы, солнечная генерация, потребление, вода и электромобиль — при наличии соответствующих служб и данных в установке.
- Суточная статистика, интервалы учёта энергии, прогноз и тарифы, предоставленные контроллером. Отсутствующие данные не превращаются в нули или полную историю.
- Выбор ESS, переключатели контроллера, режимы воды, постоянное переопределение уставки и редактор тарифов — только при поддерживаемой функции и актуальных данных.
- Настраиваемые кнопки Home, активные бытовые приборы, шторы, медиаплееры, сцены, числовые параметры, датчики и погода Home Assistant.
- Нативные предупреждения с исходным временем события; зашифрованные системные уведомления Web Push по явному согласию пользователя.
- Сохраняемые настройки, HTTP/WebSocket API, проверка `/health` и метрики `/metrics`.

Это не обещание полного совпадения с Desktop или поддержки любого оборудования. Доступность зависит от источника, прошивки, конфигурации и свежести наблюдений.

## Установка и первый запуск

Выберите конкретную версию и платформу в [Releases](https://github.com/victron-venus/inverter-dashboard-go/releases), проверьте опубликованные контрольные суммы и происхождение файлов. Beta/nightly/RC — предварительные версии. Базовая версия исходников указана в [VERSION](VERSION).

Для сборки нужен Go из [go.mod](go.mod), сейчас 1.26.9:

```sh
git clone https://github.com/victron-venus/inverter-dashboard-go.git
cd inverter-dashboard-go
go mod download
go build -trimpath -ldflags "-X main.Version=$(cat VERSION)" -o inverter-dashboard .
./inverter-dashboard --version
cp config.yaml.example config.yaml
chmod 600 config.yaml
```

**До запуска отредактируйте `config.yaml`.** Домены в примере намеренно нерабочие. Укажите свой источник и portal ID, настройте `DASHBOARD_SECRET` через приватное окружение службы. Затем запустите `./inverter-dashboard` из каталога с конфигурацией. Файл читается из текущего рабочего каталога; флага `--config` нет.

Пример слушает `127.0.0.1:8080`. Для удалённого доступа и Web Push нужен доверенный HTTPS-прокси; собственный TLS включается парой `--ssl-cert` и `--ssl-key`. В контейнере рабочий каталог — `/app`, поэтому файл обычно монтируется в `/app/config.yaml`, а не только в подкаталог `/app/config`.

## Конфигурация и сохранение данных

Полный справочник: [configuration.md](docs/configuration.md). Для MQTT задайте `mqtt.host` и `cerbo.portal_id`. Явный portal ID позволяет начать чтение даже при тихом брокере. Для IGW нужны HTTPS URL и соответствующие учётные данные. Пустой YAML `mqtt.host` с включённым шлюзом выбирает только IGW; при двух источниках предпочтителен MQTT, с переходом на шлюз при недоступности и последующей проверкой восстановления.

Порядок применения зависит от поля: YAML перекрывает обычные значения MQTT/web; явно заданные `GATEWAY_*` перекрывают YAML шлюза; затем применяются CLI-параметры и сохранённые настройки соединений MQTT/HA. Изменение соединения требует перезапуска.

Кнопки Home берутся только из вашей `homeassistant.switch_entities`. YAML-словарь со стабильными ключами сохраняет подписи, порядок `order` и признак `enabled`. Пустой словарь (`{}`) означает отсутствие кнопок; неизвестное состояние не считается выключенным. При обновлении сохраняйте свой список устройств и токены, не заменяйте их демонстрационными значениями. Прибор отображается как активный только при включённой видимости и соответствующем состоянии работы.

Для постоянных настроек задайте `INVERTER_DASHBOARD_SETTINGS_FILE`, например `/var/lib/inverter-dashboard/settings/dashboard_settings.json`. По умолчанию используется `dashboard_settings.json` в рабочем каталоге. Файл может содержать токен HA, хотя API его маскирует. Нужен приватный, доступный для записи постоянный том; read-only Secret и временный каталог не подходят. Настройки видимости применяются без перезапуска.

## Безопасность управления

Без `DASHBOARD_SECRET` встроенная аутентификация отключена. Отдельных ролей «только просмотр» нет. Предпочитайте Bearer-заголовок для API: токены в URL могут попасть в историю и журналы. `/health`, `/metrics` и выделенные статические ресурсы публичны на уровне приложения; ограничьте их на прокси при необходимости.

Сервер проверяет разрешённую цель, текущий источник и свежесть данных перед отправкой. Сохранённые retained-сообщения можно показать, но они не дают свежего разрешения на управление. Принятый запрос не доказывает физическое выполнение — проверяйте авторитетное состояние устройства.

**DRY не является общим блокиратором.** Установка и отмена постоянного переопределения уставки работают независимо от DRY по протоколу контроллера. Не проверяйте установку переключением оборудования или подтверждением настоящей тревоги. Подробности: [эксплуатация](docs/operations.md), [политика безопасности](SECURITY.md).

## События и Web Push

Повторно полученное предупреждение сохраняет исходное время; отсутствующее или неверное время остаётся неизвестным. Интерфейс обновляет относительный возраст без новых сообщений и после возврата на вкладку, позволяет увидеть точное местное время и часовой пояс. Исчезновение, подтверждение и заглушение тревоги — разные действия.

Для Web Push нужны HTTPS, поддерживаемый браузер, разрешение ОС и `WEB_PUSH_ENABLED=true` с абсолютным `WEB_PUSH_DATA_DIR` на постоянном томе. Серверное приватное хранилище поддерживается на Linux/macOS; на Windows эта функция недоступна. Хранилище рассчитано на один процесс; сохраняйте его ключи и подписки при обновлении, не удаляйте для «починки» уведомлений.

История при запуске/переподключении не рассылается заново. Ограничения: 64 подписки, 1024 ожидающие доставки, две параллельные отправки, до трёх попыток, срок события до пяти минут. API `202` означает очередь, ответ провайдера `2xx` — принятие провайдером, а не показ ОС. См. [полное описание](docs/web-push.md).

## Диагностика, интерфейс и разработка

Если страница не открывается, проверьте адрес прослушивания, DNS/VPN-маршрут, TLS и аутентификацию. Если Home недоступен, проверьте реальное чтение сущностей HA и свежесть данных, а не только значок соединения. Если настройки исчезают — путь, права и постоянство тома. Начинайте с [проверок без управления оборудованием](docs/troubleshooting.md); не публикуйте токены, endpoints Push или полный приватный конфиг.

Встроен официальный артефакт **Vue v2.2.9** (версия пакета `2.2.9`, исходник `f86943ebc764688c32bc4389f2276bc12682a90e`). [Данные о происхождении](internal/html/vue-ui-source.json) содержат метаданные и хеши файлов. Байты совпадают с прошедшей проверку RC `v2.2.9-rc.2` (сборка `39039690585`). Тексты интерфейса, даты, время, сохранённые ошибки приложения и подписи тем поддерживают английский, русский, украинский, немецкий, французский и нидерландский языки; сообщения внешних источников сохраняют исходный текст. Подробнее — [поддержка языков](docs/development.md#shared-ui-and-translations).

Для разработки используйте [руководство](docs/development.md), [CONTRIBUTING](CONTRIBUTING.md) и `bash scripts/ci.sh`. Исходники интерфейса находятся в [inverter-dashboard-vue](https://github.com/victron-venus/inverter-dashboard-vue); не редактируйте встроенные сгенерированные файлы.
